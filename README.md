Simple Questions app: is the app that accept several questions and allows the simple online environment where it support multiple questions and ...

<!-- The tech stack used -->
-React js: it is completely made in react for ui
-React js features: useState--to mannage the states like adding questions, answering and more tasks

to make sure that this is going to run on your local environment:
    run: npm install -- this is going to allows the installation of all dependencies used in this app
    run: npm run dev -- after you've to run the npm run dev to start the dev server for this app
